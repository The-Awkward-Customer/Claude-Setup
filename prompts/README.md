# Prompts

Reusable prompts and system prompts for Claude Code.

## Adding a Prompt

1. Create a `.md` file in this directory
2. Include a header with description and use case
3. Add an entry to `../CATALOG.md`

## Prompt Format

```markdown
# Prompt Name

## Description
What this prompt does.

## Use Case
When to use this prompt.

## Prompt

[The actual prompt text]
```

## Usage

Copy the prompt content and use it as a system prompt or paste it into your conversation.
