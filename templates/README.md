# Templates

CLAUDE.md templates for different project types.

## Adding a Template

1. Create a `.md` file with the template content
2. Add an entry to `../CATALOG.md`

## Template Format

Templates should be complete CLAUDE.md files that can be copied directly to a project root.

Include:
- Project type overview
- Key commands
- Architecture notes
- Conventions to follow

## Usage

1. Find a template matching your project type
2. Copy to your project root as `CLAUDE.md`
3. Customize project-specific details

## Example Categories

- Web frameworks (React, Vue, Next.js)
- Backend frameworks (Express, FastAPI, Rails)
- Languages (TypeScript, Python, Go, Rust)
- Project types (CLI tools, libraries, full-stack apps)
